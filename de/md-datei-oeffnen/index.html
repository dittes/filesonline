Was ist eine MD-Datei?

Eine .md-Datei ist ein einfaches Textdokument in Markdown, einer simplen Schreibweise für Überschriften, Listen und Links. README-Dateien, Entwicklerdokumentation und Notizen aus Apps wie Obsidian nutzen sie oft.

Jeder Texteditor kann sie öffnen, zeigt aber nur die rohen Zeichen. Dieser Viewer zeigt das formatierte Ergebnis neben einem Editor, unterstützt Tabellen, Aufgabenlisten und Code-Hervorhebung und wandelt die Datei in PDF, HTML oder reinen Text um.

So öffnest du eine MD-Datei

  1. Klicke auf „MD-Datei auswählen“ oder ziehe deine .md-Datei auf die Seite. Du kannst auch Text einfügen oder mit einem leeren Dokument beginnen.

  2. Lies die formatierte Vorschau oder bearbeite den Text und sieh, wie sich die Vorschau beim Tippen ändert.

  3. Speichere die Markdown-Datei oder exportiere sie als PDF, HTML oder reinen Text.

Häufige Fragen

Mit welchem Programm öffnet man .md-Dateien?

Jeder Texteditor kann sie öffnen, auch Notepad und TextEdit, zeigt aber die rohen Zeichen. Diese Seite zeigt die formatierte Fassung, ohne dass du etwas installieren musst.

Kann ich Markdown in PDF umwandeln?

Ja. Öffne die Datei und wähle im Exportmenü PDF. Die Datei entsteht in deinem Browser.

Kann ich HTML in Markdown umwandeln?

Ja. Füge HTML im Importdialog ein, und es wird in sauberes Markdown umgewandelt, das du weiter bearbeiten kannst.

Wird mein Dokument hochgeladen?

Nein. Dein Dokument wird in deinem Browser verarbeitet und nie an einen Server gesendet.

Funktioniert das unter Windows, Mac, iPhone und Android?

Ja, in jedem aktuellen Browser. Am Computer steht der Editor neben der Vorschau, am Smartphone stehen beide untereinander.
