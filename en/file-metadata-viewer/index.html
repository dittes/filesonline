Much more than the file properties dialog

Real file type

Identifies files by their content, not their name, and warns when the extension is wrong, a common trick for disguising risky files.

All the metadata

Authors, dates, software, camera and lens, GPS, XMP, IPTC and color profiles, shown readably or under standard field names.

Full text and summary

Extracts the text, picks out key sentences, topics and language, and finds emails, links, dates and amounts.

Files inside files

Opens email attachments, ZIP contents, images in Word files and PDF attachments, each inspected like a file of its own.

What your file reveals

Flags names, locations, tracked changes, hidden sheets and macros before you share a document with anyone.

Checksums and raw bytes

MD5, SHA-1, SHA-256, SHA-512 and CRC32, plus entropy, hex view and a check for data hidden after the end of a file.

Text from scans

Recognizes text in images and scanned PDFs with built-in OCR, in English, German, Polish and Czech.

Export for your workflow

Save as text, JSON, XHTML or CSV. Field names follow Apache Tika, so results fit existing pipelines.

How to inspect a file

  1. Choose files or drop them onto this page. Whole folders work too, and so does pasting.

  2. Read the overview, then switch between Text, Metadata, Embedded, Structure and Bytes.

  3. Copy what you need or export it. With several files, compare them all in one table.

Frequently asked questions

How do I see the metadata of a file?

Drop the file onto this page and open the Metadata tab. You get everything the format stores, such as author, dates, software and location, grouped and searchable.

How can I tell what type a file really is?

The tool reads the first bytes and internal structure of the file instead of trusting its name. If the extension does not match the content, you get a warning.

Can I see what a document reveals about me?

Yes. “What this file reveals” lists names, GPS positions, tracked changes, hidden sheets and more, and links to a tool that removes them.

Is this the same as Apache Tika?

It does the same job in your browser: detect the type, then extract text and metadata, including from embedded files. It is its own implementation and uses Tika-style field names in exports. Tika itself runs on a server or desktop with Java, and it supports more rare formats.

What are the limits?

Files up to 1 GB, depending on your device. Old Office files are read from their internal structure, so unusual documents can come out incomplete. RAR and 7Z archives can only be listed or described here, and the file manager can extract them. Rare formats often show only what their header stores.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
