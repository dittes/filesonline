Find a word or phrase in the contents of a whole folder, not just in file names. The search runs in your browser, and nothing is uploaded.

Many file types

Searches plain text and code files, PDF, Word (DOCX), Excel (XLSX), PowerPoint (PPTX), OpenDocument files and e-mails.

Hits with context

You see the number of hits per file and snippets with the match highlighted. Click a result to jump to the file and preview it.

Match case, whole words

Narrow the results by matching letter case or whole words only.

How to search inside files

  1. Click “Open folder” or “Open files”, or drop a folder onto this page. The file manager opens with the search ready.

  2. Type what you are looking for. Turn on match case or whole words if you need them.

  3. Check the snippets, then click a result to open the file in the preview.

What the search can and cannot read

Searching only file names misses most of what you are looking for. A contract, an invoice or an old e-mail is usually found by a phrase inside it. This tool reads the text of the files and searches that.

Scanned PDFs without a text layer cannot be searched, because they contain pictures of pages rather than text. The OCR PDF tool on this site can make them searchable. Files larger than 48 MB are skipped.

Frequently asked questions

Which file types are searched?

Text and code files, PDF, DOCX, XLSX, PPTX, OpenDocument files and e-mails.

Why does my scanned PDF find nothing?

A scan has no text layer. Run it through the OCR PDF tool on this site first, then search the result.

Is there a size limit?

Files over 48 MB are skipped.

Are my documents uploaded?

No. The text is read and searched in your browser.
