Remove EXIF and metadata from photos and PDFs

Delete GPS location, camera details and document properties before you share a file. The image data is not touched, so quality stays the same.

Photos and PDFs

Removes EXIF (camera, lens, date, GPS location), XMP, IPTC and comments from JPG, PNG and WebP. For PDF it removes author, title, software and dates.

No quality loss

The image data is not re-encoded. Colour profiles are kept so colours stay right, and the rotation of a photo is preserved.

Many files at once

Clean a whole folder in one go. Add cleaned copies marked “-clean”, or replace the files in the workspace.

How to remove metadata from files

  1. Click “Open folder” or “Open files”, or drop photos and PDFs onto this page. The file manager opens with the metadata tool ready.

  2. Choose whether to add cleaned copies or replace the files in the workspace, then run it.

  3. Download the cleaned files as a ZIP. In Chrome and Edge you can also save them straight into a folder.

What metadata can give away

A photo from a phone can carry the exact GPS position where it was taken, the date and time, and the model of the device. Many PDFs contain the author's name, the software used and the creation date. Most people never see this, but anyone who receives the file can read it.

This tool removes that data without re-encoding the picture, so there is no new compression and no loss of quality. It does not remove visible content: a watermark or text on the page stays as it is.

Frequently asked questions

Does removing metadata reduce image quality?

No. The image data is not re-encoded. Only the metadata blocks are removed.

Will my photo still be rotated correctly?

Yes. The rotation is preserved, and colour profiles are kept so colours look the same.

Which formats are supported?

JPG, PNG and WebP images, and PDF documents.

Does it remove watermarks or text in the picture?

No. It only removes hidden metadata, not visible content.
