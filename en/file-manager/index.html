What you can do

Browse and search

A folder tree, a list or a thumbnail grid, search across every folder, filters by file type and sorting by name, size or date.

Preview almost anything

Images, PDF, video, audio, text, code, tables, fonts and archives, plus the text of Word, Excel and PowerPoint files.

Zip and unzip

Create a ZIP from any selection with the folder structure kept. Unpack ZIP, TAR, GZ, RAR and 7Z archives.

Rename in bulk

Find and replace, numbering, dates, letter case and regular expressions, with a live preview of every new name.

Find duplicates

Identical files are found by content, not by name, and you see how much space the copies take up.

PDF work without leaving

Merge PDFs, compress them, pull out the text or turn photos into one PDF. The result lands in the same folder.

Convert and resize images

Turn images into JPG, PNG or WebP, scale them down and drop the EXIF data in one go.

Checksums and file lists

SHA-256, SHA-1, SHA-512 and MD5 for any file, checked against a value you paste. Export the file list as CSV or JSON.

Keyboard and command palette

Arrow keys, Space for Quick Look, F2 to rename, and Ctrl or ⌘ K to reach every action and tool by typing.

Works together with every tool on this site

Select a file and the file manager suggests what fits. The tool opens in a new tab with the file already loaded, and the file still never leaves your device.

How to use the file manager

  1. Click “Open folder” or “Open files”, or drop them onto this page. Only what you choose is opened.

  2. Browse, preview and select. The pane on the right shows what you can do with the selection, right here or in another tool.

  3. Download single files or a ZIP of everything. In Chrome and Edge you can also save straight into a folder. Your originals are not changed before that.

Frequently asked questions

Are my files uploaded?

No. All file operations happen inside your browser. There is no server that could receive your files.

Does renaming or removing change my real files?

No. The file manager works on a copy of the file list, the workspace. Files on your disk only change when you download results or save them into a folder yourself.

How do files get to the PDF tools?

They are placed in your browser's own storage for a moment and picked up by the tool in the new tab. No server is involved, and the copy is removed as soon as the tool has it.

Which archive formats can I extract?

ZIP, TAR and GZ are unpacked with code that ships with this site. RAR and 7Z need a WebAssembly library that is fetched from a public CDN the first time you unpack one.

Can it access my whole computer?

No. It only sees the files and folders you explicitly choose, and that access ends when you close the tab.

Which browser works best?

Chrome and Edge offer the most, including saving into a folder. Firefox and Safari handle everything else, and results are downloaded instead.
