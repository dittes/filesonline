What you can do

How to use the file manager

  1. Click “Open folder” or “Open files”, or drop them onto this page. Your browser asks for permission, and only what you choose is opened.

  2. Browse, preview, search, rename or zip your files using the tabs at the top.

  3. Download the result. In Chrome and Edge you can also save directly back to the folder.

Frequently asked questions

Are my files uploaded?

No. All file operations happen inside your browser. There is no server that could receive your files.

Which archive formats can I extract?

ZIP works in every browser. RAR, 7Z and TAR are extracted with a small WebAssembly library that is loaded when you first need it.

Can it access my whole computer?

No. It only sees the files and folders you explicitly choose, and that access ends when you close the tab.

Which browser works best?

Chrome and Edge offer the most, including saving back to a folder. Firefox and Safari handle everything else, and results are downloaded instead.
