Compare two folders and find the differences

Check a backup or a copy by comparing two folders side by side. The comparison runs in your browser and your files are not uploaded.

or drop files and folders here

  • No upload
  • Free
  • No account
  • Works offline once loaded

Four clear results

Files are matched by relative path. You see what is only in A, only in B, what is different, and how many files are identical.

Size or exact contents

By default, different means a different size. An option compares contents exactly with SHA-256.

Report and fix

For differing files you see both sizes and which one is newer. Export the report as CSV, or copy the files missing in B into B within the workspace.

How to compare two folders

  1. Click “Open folder” or “Open files”, or drop both folders onto this page. The file manager opens with the compare tool ready.

  2. Pick the two folders to compare. Switch on exact content comparison if sizes are not enough.

  3. Review the results, export the CSV report, or copy missing files into B. Download the result as a ZIP.

Checking a backup or a copy

After copying a large folder to a drive or a backup, it is hard to be sure that everything arrived. Comparing the two folders by relative path shows what is missing on one side and what exists on both.

The quick comparison looks at file size. It is fast and shows missing or incomplete files. If you need certainty, turn on the content comparison, which compares the files with SHA-256. Copying files into B happens inside the workspace, so nothing on your disk changes until you download or save the result.

Frequently asked questions

How are files matched?

By their relative path inside each folder. A file counts as the same only if it has the same path in A and B.

Does it compare contents?

By default it compares size. Switch on the exact option to compare contents with SHA-256.

Can I keep the result?

Yes. Export the report as a CSV file.

Does it change my folders?

No. Copying missing files into B only changes the workspace. You download or save the result yourself.
