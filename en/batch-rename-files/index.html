Batch rename files in your browser

Combine simple rules to rename hundreds of files at once and check every new name before anything changes. Your files stay on your device.

or drop files and folders here

  • No upload
  • Free
  • No account
  • Works offline once loaded

Rules you can combine

Find and replace with optional regular expressions, text before or after the name, numbering, a date prefix and changes to letter case or the extension.

Live preview

Every old and new name is listed side by side and updates as you type. If two files would end up with the same name, a number is added automatically.

Originals stay untouched

Renamed files are downloaded as a ZIP or saved to a folder. The files on your disk keep their old names.

How to rename files in bulk

  1. Click “Open folder” or “Open files”, or drop files onto this page. The file manager opens with the rename tool ready.

  2. Add your rules and watch the preview. For example, replace spaces with hyphens, switch to lowercase and add a number at the end.

  3. Download the renamed files as a ZIP. In Chrome and Edge you can also save them straight into a folder.

Renaming options in detail

Letter case can be set to lowercase, UPPERCASE, Title Case, kebab-case or snake_case. Numbering lets you choose the start value and the number of digits, and place the number first, last or in place of the whole name. You can also start each name with the file's modification date, which keeps files in date order when sorted by name.

Regular expressions are optional. Plain find and replace works for most jobs. Because the preview shows the result first, you can adjust the rules until every name looks right and only then download.

Frequently asked questions

Does it rename the files on my disk?

No. The tool works on a copy of the file list. You get the renamed files as a ZIP or in a folder you choose, and the originals keep their names.

What happens if two files get the same name?

The tool adds a number to the later one, so no file overwrites another.

Can I number the files?

Yes. Choose the start value and the number of digits, and place the number first, last or in place of the name.

Do I need to know regular expressions?

No. They are an option. Normal find and replace, numbering and letter case cover most renaming jobs.
