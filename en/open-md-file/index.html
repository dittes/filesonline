What is an MD file?

An .md file is a plain text document written in Markdown, a simple way to mark headings, lists and links. README files, developer documentation and notes from apps like Obsidian often use it.

Any text editor can open one, but you only see the raw symbols. This viewer shows the formatted result next to an editor, with support for tables, task lists and code highlighting, and converts it to PDF, HTML or plain text.

How to open an MD file

  1. Click “Choose file” or drop your .md file onto the page. You can also paste text or start with an empty document.

  2. Read the formatted preview, or edit the text and watch the preview update as you type.

  3. Save the Markdown file, or export it as PDF, HTML or plain text.

Frequently asked questions

What app opens .md files?

Any text editor can open them, including Notepad and TextEdit, but they show the raw symbols. This page shows the formatted version without installing anything.

Can I convert Markdown to PDF?

Yes. Open the file and choose PDF in the export menu. The file is created in your browser.

Can I convert HTML to Markdown?

Yes. Paste HTML into the import dialog and it is converted to clean Markdown you can keep editing.

Is my document uploaded?

No. Your document is processed in your browser and never sent to a server.

Does it work on Windows, Mac, iPhone and Android?

Yes, in any current browser. On a computer you get the side-by-side editor, and on a phone the two panes stack.
